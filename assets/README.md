# Ảnh tạm thời cho game mèo

Bỏ 9 ảnh hiện có vào các thư mục dưới đây. Tên file là đề xuất; giữ đúng phần mở rộng thực tế của ảnh, không đổi JPG thành PNG chỉ bằng cách đổi tên.

```text
assets/
  cats/
    body/
      body_01.png          # 1 thân
    face/
      face_01.png          # mặt 1
      face_02.png          # mặt 2
      face_03.png          # mặt 3
    weapon/
      weapon_01.png        # vũ khí 1
      weapon_02.png        # vũ khí 2
    accessory/
      head/
        head_01.png        # 1 phụ kiện đầu
  environment/
    environment_01.png     # môi trường 1
    environment_02.png     # môi trường 2
```

Ảnh thân, mặt, vũ khí và phụ kiện nên có nền trong suốt. Cứ giữ nguyên ảnh gốc và kích thước hiện tại; sau khi có ảnh sẽ kiểm tra điểm neo và cách ghép. Hai ảnh môi trường đang để chung, sẽ phân loại nền, tile hoặc vật cản sau khi xem nội dung.

Các file `.gitkeep` chỉ giữ thư mục trống trong Git, không phải ảnh. Hiện chưa có ảnh được sao chép hoặc tạo mới trong các thư mục này.
