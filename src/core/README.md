# Core contract and MVP decisions

Import public APIs from `src/core/index.ts`. The module is independent of Phaser and DOM rendering. `types.ts` is the shared contract. Read-only state snapshots are detached JSON-compatible objects. Invalid actions throw without changing state. All randomness is injectable (`rng` in factory/store/engine); `seededRandom(seed)` is available for reproducible scenarios.

## UI integration

- `new GameStore(options?)`: `getState()`, `subscribe(listener)` (future changes only; returns unsubscribe), `gacha(name?)`, `breed(fatherId,motherId)`, `setRoster(ids)`, `recordBattle(result)`. Initial save has three cats and a three-cat roster. `persistenceWarning` describes unavailable or invalid storage. `MemoryStorage` works outside the browser.
- `new CatFactory(options?).createF0(name?)`; `breedCats(father,mother,options?)`. Injection options: `rng`, `id`, `now` (milliseconds).
- `new TacticalEngine({size,terrain?,units,rng?,id?})`: `getState()`, `getReachable(unitId?)`, `getAttackable(unitId?)`, `hasLineOfSight(attackerId,targetId)`, `move(position)`, `attack(targetId)`, `wait()`, `endTurn()`. Legal movement includes a cheapest orthogonal path and total cost. Legal attacks return unit IDs. Rendering must use these APIs rather than compute legality separately.
- `terrain[y][x]`, with `createTerrain(8|10)` for an empty grid. `units` use current battle HP separately from immutable cat maximum HP. Units at HP zero remain in snapshots for animations but do not occupy tiles, block sight, act, or appear in the timeline.
- `events` describes only the most recent command, including turn advancement after move/attack. `timeline` lists living units ordered by their next scheduled opportunity; the active unit comes first. `result` becomes available only when a team has no living units. Pass it once to `store.recordBattle`; duplicate battle IDs receive no further reward, including after reload.

## Resolved ambiguities

The supplied task list defines the MVP; GDD systems not required there are deferred. There is no network/server, PvP authority, Telegram integration, counterattack, AoE, critical multiplier, equipment defense, healing, destructible walls, or jump-through-obstacle skill. The supported accessory passive is `skirmisher`, explicitly allowing attack then move. Other cats move then attack, or attack and end their turn. Any unit can `endTurn()` after a partial turn; `wait()` requires a completely unused turn.

- F0's 100 integer base points are divided among HP, ATK and SPD, at least 10 per attribute. MOV/RNG come from face/weapon genes, not a second point budget; accessory contributes zero points. Base conversions linearly map 10..80 points to HP 300..800, ATK 30..120, SPD 20..90, then apply the relevant gene rarity multiplier (1/1.2/1.45/1.8). These base ranges precede rarity multipliers.
- F0 gene rarity is independently common 75%, rare 20%, epic 5%; God only appears through mutation. These gacha rates are tuning assumptions, not specified rates. Cat rarity is the highest gene rarity. Current content is three variants per layer, with text identifiers for UI sprite lookup.
- Each of four child genes independently inherits father on [0,.45), mother on [.45,.9), mutates on [.9,1). Mutation chooses a parent as the reach/point source. Face mutation sets that gene to God and adds one MOV (cap 5); weapon mutation sets God and adds one RNG (cap 4). A mutation does not automatically grant both bonuses. Body/accessory mutation rerolls a non-God variant. F1 points are inherited per gene; their total need not be 100. Historical bonuses are retained within inherited reach, never double-counted.
- Movement uses Dijkstra to expose all minimum-cost reachable tiles, equivalent to shortest weighted paths for these small grids. Units of either team block walking. Water costs 2; leaving a cell orthogonally adjacent to an enemy doubles the entry terrain cost (so water plus ZoC costs 4). Entering ZoC alone does not double cost. Pit blocks movement but not sight. Walls block both. A unit has one movement command per turn, regardless of unused MOV.
- Bresenham checks intermediate cells, excluding attacker/target. Walls block direct and lobbed attacks. All living intermediate units block direct attacks; lobbed attacks ignore units. Bush does not block sight and grants 20% evasion; stealth is deferred. Weapon `minRange` supports blind spots.
- SPD uses an absolute-time scheduler: first opportunity at `100/effectiveSPD`; each completed turn schedules the next at current time plus the same delay. This provides individual turns with faster units recurring sooner. Stable ties use effective SPD then lexical unit ID. Water reduces effective SPD by 15% at scheduling time. Moving to/from water affects the next delay, without retroactively rescheduling other units. An untouched Wait uses 80% of the normal delay.
- Damage is rounded `ATK * (0.9 + rng()*0.2) - defense`, minimum 1 on a hit, HP floored at zero. No base miss chance; bush alone adds a 20% evasion roll. The injected RNG returns values in [0,1), so the upper 1.1 multiplier is approached rather than included.
- Local tuning constants (`ECONOMY`): start 300 Catnip, gacha 100, breed 150, victory 100, defeat 25. Parents are retained, no cooldown. Rewards trust local engine results and are not a security boundary. Browser saves are versioned and validated; malformed/unsupported saves restart a local game with a visible warning. Writes that fail keep the session playable in memory.

## Checks

Node 22.18+ (or Node 24/26) supports the test script's TypeScript stripping. Run `npm test` for deterministic core tests and `npm run typecheck` for compiler validation. `npm run build` additionally needs the frontend-owned `index.html` and entry module.
